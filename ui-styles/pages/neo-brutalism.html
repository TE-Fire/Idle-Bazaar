风格实现要点

  • 结构色：border: 3px solid #000 + box-shadow: 6px 6px 0 #000（零模糊的硬阴影）
  • 零圆角（border-radius: 0），高饱和平涂色块，常见Combo：黄 #FFE01B / 粉 #FF7BAC / 蓝 #4D9FFF
  • 巨号粗体标题 + 网点纸背景（radial-gradient + background-size）
  • 天然优势：高对比度是结构性的而非偶然的 → 直接满足 WCAG 2.2；零 GPU 开销；全浏览器渲染一致
  • 适合：开发者工具、潮牌、校园/年轻向产品 —— 2024 年起增长最快的流派
