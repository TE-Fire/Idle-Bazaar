风格实现要点

  • 三个层次：生成式界面（按意图实时拼装组件）→ 自适应布局（高频前置 / 低频折叠）→ 代理式体验（从操作转向委托）
  • 本页「自适应」用纯 CSS 复刻：#dense:checked ~ .wrap .low { display:none } —— 点右上角开关看布局自动重组
  • 生成状态必须有视觉语言：流式光标 + 骨架屏 shimmer（@keyframes 移动 background-position）+ 意图链路 chips
  • 设计师角色转变：从"画界面"到"设计规则" —— 定义品牌规范、交互边界、组件生成约束
  • 毕设风险：AI 部分容易吃掉评审焦点；若选题为此，需把 LLM 调用与非 AI 对照组都做出来才站得住
