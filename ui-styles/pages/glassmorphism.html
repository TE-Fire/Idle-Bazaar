风格实现要点

  • 三件套：backdrop-filter: blur(18px) + background: rgba(255,255,255,.10) + border: 1px solid rgba(255,255,255,.22)
  • 必须有东西可糊：背景要放真正位图色块 / 渐变光斑（本页 4 个 filter: blur(90px) 的彩色圆形），糊静态纯色是没效果的
  • 再加一层 inset 0 1px 0 rgba(255,255,255,.35) 顶部高光，玻璃的边缘厚度立刻出来
  • 坑：低端安卓 GPU 开销大 → 限制单个滚动容器内的模糊面数量；正文区要留不透明阅读区保住对比度
  • Tailwind 一行搞定：backdrop-blur-md bg-white/10 border-white/20
