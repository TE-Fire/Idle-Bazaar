本次拍板的三项决策

未决问题决策落地方式（保持可扩展）
微信订阅消息 不接入 改为站内消息中心：三分区（私信 / 系统通知 / 交易通知），红点与角标在站内模拟。后续若申请到模板，由服务端下发后在「系统通知」区同源展示，UI 不需改版。
面交导航 / 第三方地图 不调起 地图区做成静态校园示意图（楼栋轮廓 + 路网 + 定位 pin），保持「地图容器 + 导航按钮」的组件拆分。后续接入只需把导航按钮换成 wx.openLocation，版式与数据字段不变。
信用分是否对外可见 只显示等级 对外呈现「信用高 / 中 / 低」+ 三格进度条，不暴露具体分数，避免攀比与刷分。分数仅管理端可见，用于搜索权重与人工审核判定（低于 60 分强制人工审核）。

说明

· 原型尺寸 375×812，CSS 以 px 呈现：1pt = 1px = 2rpx，落地时数值 ×2 写 rpx。
· 样式集中在 mini.css（Token 唯一出处，来自 design/02-移动端小程序-UI设计规范.md），各页面只写结构，不写死色值。
· 交互为纯 CSS（:active 按压态、radio 切换分区），无 JS，可直接静态托管演示。
· 业务流程依据 business/02-移动端小程序-业务与流程.md；视觉依据 design/02；状态机以 business/03-管理端 为准。
· 图片均为本地 CSS 占位块，无外网依赖。
