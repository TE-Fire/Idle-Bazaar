本次拍板的三项决策

未决问题决策落地方式
议价是否作为独立业务 不作为 「可议价」降级为商品展示标签（卖家勾选），买家在聊天里口头问价即可。平台不做报价/还价流程，订单金额一律按标价成交；对比维度与筛选条件均不出现议价。聊天中的议价卡改为普通文本消息。
是否需要预定机制 不需要 取消商品「已预定」状态。拍下生成待付款订单（30 分钟超时取消），付款前商品不锁定，先付款先得；付款成功后商品转「已售出」，其余待付款订单自动取消并通知。以付款为唯一占位判据，避免一物多卖的复杂状态。
是否开放置顶 / 推广 不做 商品管理只保留编辑 / 下架 / 删除；管理端同样没有置顶操作。排序靠学区、成色、时间与信用权重，不引入商业化曝光位。
