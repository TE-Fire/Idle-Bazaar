管理端 Web 原型（A1–A9）

方向：Y 分析台 Light Card（Ant Design Pro 风格）· 主色蓝 #1677FF · 仅适配 ≥1280px，不做移动端。 视觉依据 design/03-管理端Web-UI设计规范.md，业务依据 business/03-管理端-业务与流程.md。 样式与权限逻辑分别收在 admin.css / admin.js，页面内不写死色值。

入口

A1登录与角色分流
账号 + 密码 + 图形验证码。四个演示账号对应四种角色，登录后菜单与按钮按权限点真实渲染，无权限项不出现。
关键：权限隔离真实实现（前端渲染 + 后端同矩阵校验）

P0 · 核心处置

A2数据看板
KPI×4 → 审核时效 SLA → 趋势 → 构成 → TOP-N → 待处置队列 → 异常预警。共 5 张图表（规范上限）。
新增：SLA 指标卡（平均首审 / 达标率 / P95 / 积压 / 单条处置）+ 近 14 日首审时长柱图
A5审核队列
商品审核 / 举报 / 申诉三 Tab。按权重分排序而非时间；Drawer 内完成四项判读，支持连续审核（J / K）。
关键：等待时长列标出临期与超时，SLA 落到操作层
A3商品管理
表格 + 筛选 + 批量下架 / 删除 + 详情 Drawer（含状态流转时间轴）。
边界：无置顶推广、不代卖家改价改描述
A4用户管理
全部用户 + 学号认证审核。认证为低频高责任动作，不做批量通过；信用分仅本端可见。
关键：姓名 / 学号 / 学院三项核对 + 常见驳回原因预设

P1 · 订单、配置与数据

A6订单管理
六状态 Tab + 订单详情 + 纠纷介入 Drawer。
关键：取证看商品快照而非当前商品；当面拒收不计违约
A7内容管理
四张字典：分类树 / 成色等级 A–D / 面交点 / 学院与校区。全端一致性的源头，后台下发，三端不得硬编码。
A8数据报表
校园独有四张图：学期时间轴对比 / 学院×品类热力矩阵 / 校内面交所热力 / 二手循环率（减碳）+ 审核员 SLA 明细。
关键：减碳系数标注为估算假设，附系数表与三条局限

P2 · 系统

A9系统设置
管理员账号 / 角色权限矩阵 / SLA 阈值配置 / 操作日志。仅超级管理员可见。
关键：review.judge 与 user.ban 互斥
本次三项未决问题的落地
① 权限隔离真实实现：以「权限点」为最小粒度（16 个），四种角色各自持有子集；前端按 data-perm 渲染菜单与按钮，无权限的菜单项直接不渲染、按钮置灰加锁； 页面顶部角色条实时显示「本页已按角色隐藏/锁定 N 个操作」；同一张矩阵在后端做接口鉴权，前端隐藏只是体验层。用右上角「切换角色」可逐角色验证。
② 审核时效 SLA：定为两级指标——响应时效（首审 ≤ 2h 达标、P95 ≤ 6h、达标率 ≥ 95%、超 24h 记积压红牌）与操作效率（单条平均处置 ≤ 30s），两者不可混用； 看板新增 SLA 卡、审核队列「等待时长」列标临期/超时、报表新增分审核员明细、设置页可调阈值。
③ 减碳系数：明确标注为估算假设而非实测。报表页循环率卡片内嵌警告条，并提供「系数与假设」弹窗（系数表 + 计算公式 + 三条已知局限 + 改进方向）。

演示建议　用 login.html 分别以「审核员 / 只读」登录，对比审核队列页的操作列与左侧菜单，权限差异一眼可见。
