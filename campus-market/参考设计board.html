两个待定问题的建议

小程序 or App？

  1. 时间紧 / 求稳：微信小程序 + Web 管理端。这是同类毕设的标准配置，风险最低，扫码即可演示。
  2. 想加分：用 uni-app（或 Taro）写一套代码，同时编译出小程序 + H5 + 安卓 APK。答辩时三端同屏，论文里能写成"多端一致性方案"，明显比单做一个假 App 扎实。
  3. 共同的坑：微信支付要商户资质，个人主体基本申请不下来。毕设通用解法是做模拟支付 + 线下交付（线下自提反而贴合校园场景）。
  4. 登录用 wx.login 一键获取；在此之上加学号/校园邮箱二次认证，这是校园平台最有说服力的一张牌。

管理端可视化做什么才有亮点？

  • 学期时间轴对比：学期初 / 学期末 / 毕业季三个流量峰值，做成年度热力条
  • 学院 × 品类热力矩阵：哪个学院在交易什么，这是纯校园才有的数据故事
  • 面交所热力图：校内地图上的交易热点地点（楼栋 / 宿舍区）
  • 循环率指标卡：二手循环带来的减碳估算，ESG 角度很出挑
  • 预警区：异常交易 / 刷量 / 价格异常，运营动作入口（这块功能本身也能写论文）
  • 图表数量控制在一屏 3–5 个，再多阅读成本陡增
