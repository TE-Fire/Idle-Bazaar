## 一、设计原则

| # | 原则 | 落地判据 |
|---|---|---|
| 1 | **逛得下去** | 首页必须是无限流；用户第 3 秒内要看到至少 4 件商品，不能先看到搜索框和分类 |
| 2 | **图片压倒一切** | 卡片图片占比 ≥ 60%；文字只保留标题 + 价格 + 成色，其余折叠 |
| 3 | **拇指优先** | 所有高频操作落在屏幕下 1/3；发布按钮悬浮右下且避开安全区 |
| 4 | **半熟人信任可见** | 学号认证、同校、面交点三项必须能在卡片或详情页一眼看到 |
| 5 | **主色克制** | 橙色只给：发布按钮、选中态、价格。分类金刚区图标**各用一色**（2026-10-24 参考美团改版，取代早前「转转教训」的单色决定） |

## 二、小程序平台硬约束（先读，再设计）

| 约束 | 说明 | 应对 |
|---|---|---|
| 单位 rpx | 750rpx = 屏宽。基准屏 375pt → **1pt = 2rpx** | 本文档尺寸以 pt 表述，实现时 ×2 转 rpx |
| 顶部导航 | 系统导航栏右侧胶囊固定存在 | 自定义导航必须读取状态栏高度动态适配；**默认方案：用系统导航栏，不做自定义** |
| TabBar | 原生 tabBar 只能配颜色与图片（icon 81×81 png），**选中态与切换过程无法做动画** | v1.1 起改为**自绘 dock**（`components/TabBar.vue`），`pages.json` 不再声明 tabBar；5 项：首页 / 分类 / 发布 / 消息 / 我的；tab 间跳转统一走 `utils/tab-nav.ts#goTab`（reLaunch） |
| 无 hover | 触屏没有悬停态 | 所有 hover 改为 `:active` 按压态（底色变深 8% 或缩放到 0.97） |
| 页面栈 | 最多 10 层，超出无法跳转 | 详情页 → 卖家主页 → 商品详情 的链路用 `redirectTo` 截断 |
| 字体 | 只能用系统字体；自定义字体需网络加载且首屏闪烁 | 中文字体栈：`-apple-system, "PingFang SC", "HarmonyOS Sans"`；数字用系统默认 |
| 安全区 | iPhone 全面屏底部 34pt 危险区 | 底部固定元素加 `padding-bottom: env(safe-area-inset-bottom)` |
| 图片 | 列表必须懒加载，否则长列表内存爆 | `image` 组件 `lazy-load`，列表页首屏外延迟加载 |
| 长列表 | 超过 100 条会卡 | 用 `scroll-view` + 分页；uni-app 下开启 `virtual-list` 或 `recycle-list` |
| 原生反馈 | 优先用 `wx.showToast` / `showModal` / `showActionSheet` | 不自己写 Toast 组件 |
| 阴影 | v1.1 起**允许一层软阴影**（此前一律禁用）。WXSS 的 `box-shadow` 是合成层绘制，单层、低透明度、不做动画即可控 | 卡片用 `--shadow-sm`，浮层/底部栏用 `--shadow-md` / `--shadow-dock`；**同一元素只挂一层**，且不要在 `transition` 里过渡 `box-shadow` 的大扩散值 |
| 固定定位 | 页面根节点**不能带 transform**（含 animation-fill 保留的 transform），否则会成为 `fixed` 后代的包含块，底部导航被钉到文档末尾 | 页面入场只动 `opacity`；竖向位移挂在内容块（`.cm-in`）上。此坑已在 2026-10-28 实测踩到 |

## 三、Design Token

### 3.1 Primitive（三端共用，见 `01-Web用户端-UI设计规范.md` 2.1）

### 3.2 Semantic（小程序映射）

```css
:root{
  /* 主色：橙。与 Web 端的黄同属暖色高饱和家族，
     取深一档是因为小屏上黄底+黑字在小尺寸控件（Tab 选中、图标）可读性差，
     橙底白字在 44pt 以下控件上更稳。 */
  --brand:        #FF6A00;
  --brand-hover:  #E85F00;
  --brand-glow:   #FF9A4D;   /* 渐变亮端，只用于 135deg 渐变的第一停 */
  --brand-2:      #FF4D6D;   /* 渐变暖端：身份卡 / 未读角标 的第二停 */
  --brand-bg:     #FFF1E6;   /* 选中底色 */
  --brand-text:   #C25A00;   /* 浅底上的品牌文字 */
  --price:        #FF5500;
  --accent-teal:  #00BFA5;   /* 图标块语义色：完成 / 认证 */
  --accent-violet:#6C5CE7;   /* 图标块语义色：广场 / 订单 */

  --bg:      #F6F5F7;   /* 页面底（比 v1.0 略暖，避免纯灰的"廉价感"） */
  --bg-warm: #FFF9F4;   /* 顶部洗底，与 --bg 组成 180deg 渐变 */
  --surface: #FFFFFF;
  --border:  #EFEFEF;
  --border-ctrl:#DCDCE2;
  --text-1:  #23232A;
  --text-2:  #6A6A6A;
  --text-3:  #A0A0A0;

  /* 间距：4pt 基准（=8rpx 步进） */
  --s-1:4pt; --s-2:8pt; --s-3:12pt; --s-4:16pt; --s-5:20pt; --s-6:24pt; --s-8:32pt;

  /* 字阶：body=14pt（28rpx），比 Web 端略大一号；
     2xl / 3xl 是 v1.1 新增，只给页面大标题与详情页价格 */
  --f-xs:11pt;  /* 22rpx 元信息 */
  --f-sm:12pt;  /* 24rpx 次要 */
  --f-base:14pt;/* 28rpx 正文/卡片标题 */
  --f-md:16pt;  /* 32rpx 区块标题 */
  --f-lg:19pt;  /* 38rpx 卡片价格 */
  --f-xl:22pt;  /* 44rpx 页面标题 */
  --f-2xl:26pt; /* 52rpx Hero 标题（东广场 / 消息页大标题） */
  --f-3xl:30pt; /* 60rpx 详情页价格 */

  /* 圆角：v1.1 整体放大一档，卡片 18pt 是新的默认 */
  --r-sm:4pt; --r-md:6pt; --r-lg:10pt; --r-xl:14pt; --r-2xl:18pt; --r-3xl:24pt; --r-pill:999pt;

  /* 阴影：单层、低透明度，共四档 + 两个语义专用 */
  --shadow-xs:   0 1px 2px rgba(27,27,33,.04);   /* 内嵌分组 */
  --shadow-sm:   0 2px 10px rgba(27,27,33,.06);  /* 默认卡片 */
  --shadow-md:   0 8px 24px rgba(27,27,33,.08);  /* 浮起：搜索框 / Hero 卡 */
  --shadow-lg:   0 12px 32px rgba(27,27,33,.10); /* 弹层 */
  --shadow-brand:0 8px 20px rgba(255,106,0,.28); /* 主按钮投影 */
  --shadow-dock: 0 -4px 24px rgba(27,27,33,.08); /* 底部 dock 向上投影 */

  --tab-h:58pt; --nav-h:44pt; --safe-b:env(safe-area-inset-bottom);
}
```

**字重**：400 / 500 / 600 / 700。小程序内不要用 800（PingFang 无此字重会合成，发虚）。价格用 700。
**行高**：正文 1.6；卡片标题 1.42；价格 1.1。
**渐变口径**：全端只用一种角度——`linear-gradient(135deg, --brand-glow, --brand[, --brand-2])`；
浅色装饰面用 `linear-gradient(160~180deg, 暖白, --bg)`。禁止第三个角度，否则整端"亮面"方向会打架。

## 四、布局与页面骨架

### 4.1 首页（P0，最重要的一页）

```
┌ 系统导航栏 44pt ─────────────────────────┐
│ 暖色渐变头（160deg：#FFE3C9 → #FFF3E8 → --bg）│
│  晚上好，同学            [广场] [消息]     │  ← 问候按时段切换，右侧两个玻璃按钮
│  [ 搜索框 42pt 白底 + --shadow-md ] 搜索  │  ← 不再是吸顶灰条，而是头部唯一实心亮面
├─ 金刚区（白色浮起卡，负 margin 压住渐变）──┤  ← 5×2 十格，渐变磁贴 + 白字（§5.3）
├─ 面交保障位（浅暖渐变 + 两个光斑 + 去发布）─┤  ← 给「一屏全是商品」加节奏
├─ 频道 chips（横向滑动，选中渐变填充）─────┤
├─ 区块标题「▍为你推荐  按发布时间排序」────┤
├─ 双列瀑布流 ─────────────────────────────┤
│  ┌──────┐  ┌──────┐                      │   间距 12pt，卡片 18pt 圆角 + --shadow-sm
│  │ 图 1:1│  │ 图   │                      │
│  │ 标题 │  │ 标题 │                      │
│  │ ¥价  │  │ ¥价  │                      │
│  │ 成色·校区│ │      │                      │
│  └──────┘  └──────┘                      │
│  （无限滚动，底部三点呼吸代替「加载中…」）  │
└──────────────────────────────────────────┘
  [回到顶部 40pt 胶囊，滚动 400pt 后浮现]      ← v1.1 取代原右下发布 FAB
├─ 自绘 dock 58pt + 安全区（§4.2）───────────┤
```

**关键**：瀑布流左右两列**不等高**是允许的，但同一列内必须对齐；卡片高度差由图片比例产生，文字区固定。
**为什么删掉发布 FAB**：dock 中央已有上浮的发布钮，两个入口同时出现会让用户犹豫，且 FAB 会压住最后一张卡片。

### 4.2 底部导航（自绘 dock，5 项）

```
        ╭─────────────────────────────────────╮
        │  ⌂      ▦      (＋)      ✉      ☺   │  ← 圆角 24pt 顶部，--shadow-dock
        │ 首页   分类          消息   我的    │
        ╰─────────────────────────────────────╯
              ↑ 选中项背后有 42×28pt 的浅橙光块，随切换平移 320ms
```

| 项 | 图标 | 说明 |
|---|---|---|
| 首页 | house（描边房子） | 默认页 |
| 分类 | grid（2×2 实心方块） | 全部分类树 |
| **发布** | plus（白十字，直径 49pt 上浮 13pt，品牌渐变 + `--shadow-brand`） | 视觉重心；**已在发布页时十字转 45° 并回落**，表示「收起」 |
| 消息 | chat（圆角气泡） | 右上角未读胶囊，来自 `/api/chat/conversations` 未读求和，失败静默为 0 |
| 我的 | me（头 + 肩弧） | — |

**规则**：
- 选中态 = 图标转 `--brand` + 文字 `--brand` / 600 + 背后光块平移到位；未选中 `--text-3` / 400
- 光块位移用 `transform: translateX(n×100%)`，宽 20% 每格，**不改变宽高**，避免触发布局
- 切换走 `reLaunch`（语义等同原 switchTab），每页自己跑一次入场淡入，视觉上是「换了一页」而不是「硬切」
- 每个 tab 页必须加 `.cm-page--tab`（内部按 dock 高度留出 `padding-bottom`），否则最后一条内容被压住

## 五、组件规范

### 5.1 商品卡片（瀑布卡）

| 项 | 规范 |
|---|---|
| 宽度 | `(屏宽 - 32pt - 12pt) / 2`，375 屏约 165pt |
| 卡片 | 白底 + `--r-2xl`（18pt）+ `--shadow-sm`；按压时缩到 `.97` 且阴影降到 `--shadow-xs` |
| 图片 | 方图 1:1（闲鱼口径，比 4:3 更整），`mode="aspectFill"`；底部叠 30% 高的极淡压暗，避免白底图糊边 |
| 标题 | `--f-base`，最多 2 行，`line-clamp:2`，行高 1.42 |
| 价格 | `--f-3xl`（详情页）/ 22pt（卡片）700 `--price`，`¥` 与小数各降一档；右侧可选原价删除线 `--f-xs` `--text-3` |
| 元信息行 | 成色标签（绿描边）+ 校区，`--f-xs` `--text-3` |
| 卖家行 | 14pt 渐变圆点 + 昵称 + 认证小标（已认证才显示）+ 相对时间；顶部一条 hairline 与正文分隔 |
| 角标 | 图片左上：「急出」渐变橙、「可售」半透明黑，均为 pill；字重 700 |
| 间距 | 卡片间 12pt，距屏幕左右各 16pt |

### 5.2 搜索框

- 高 42pt，圆角 pill，**白底 + `--shadow-md`**（v1.1 从「灰底平贴」改为「白底浮起」，因为头部底色已经是暖渐变，灰底会糊成一片）
- 左侧 18pt 放大镜 `--text-3`；右侧 30pt 高「搜索」胶囊，品牌渐变 + 白字
- 首页参与头部渐变、不吸顶；详情/列表页隐藏

### 5.3 金刚区（分类入口）

- 每行 5 个，两行共 10 个；不做横向分页（10 格排满：8 个字典一级分类 + 全部分类 + 发布）
- 分类数据走字典接口 `/api/dict/all`，**不得硬编码**（tech/02 §七）；色相按分类名映射，未登记分类回落灰
- 磁贴 46×46pt，`--r-2xl`，**双停渐变 + 顶部高光**（内嵌 22% 白色圆），投影取同色 `rgba(...,.55)` 向下 5pt、扩散 -4pt——平涂色块会让 10 个入口糊成一块
- 「全部分类」白底描边弱化、「发布」品牌橙实色强化，用样式强弱做层级
- 入场：每格错峰 35ms 上浮淡入，整块 320ms 内完成
- 点击反馈：整格可点，按下图标 scale(0.9) 快速回弹；入场错峰上浮（每格晚 40ms）
- 点击分类格带意图跳分类页并选中该一级分类（switchTab 不能带参，走 `utils/nav-intent.ts` 模块级一次性意图）
- 文字 `--f-xs` `--text-2`，单行省略号

### 5.4 成色标签（本平台核心组件）

| 评级 | 文案 | 颜色 |
|---|---|---|
| A | 全新未拆 | `--green-600` |
| B | 几乎全新 | `--green-600` |
| C | 轻微使用 | `--orange-400` |
| D | 明显使用 | `--text-2` |

四端（Web / 小程序 / 后台 / API）必须使用同一套 A–D 编码，文案与颜色一一对应。

### 5.5 其他

| 组件 | 规范 |
|---|---|
| 回到顶部 | 40pt 圆形白底 + `--shadow-md`，距右 16pt、距 dock 顶部 20pt；滚动超过 400pt 后以「缩 0.7 + 上移 12pt」入场（回弹曲线 260ms），点击 320ms 平滑回顶 |
| 区块标题 | 左侧 4×15pt 品牌渐变竖条 + `--f-md` 700 标题 + `--f-xs` 副标题；右侧可挂「更多 ›」。竖条替代旧的一条横线，给标题一个明确起点 |
| 骨架屏 | 首屏用骨架卡（`--r-2xl` + 1.3s 微光扫过），不用全屏 loading；数量与真实列数一致 |
| 空状态 | 描边图标（`--text-3`）+ 主文案 + 一行具体引导（「换个频道看看，或者自己发一件」而非「暂无数据」） |
| 加载更多 | 底部三点呼吸（10pt 圆点，错峰 150ms），不用「加载中…」文本；到末尾才显示「没有更多了」 |
| 下拉刷新 | 保留系统默认样式，配色与 `--brand` 一致 |
| Toast | 用 `wx.showToast`，`icon:none`，时长 1500ms |

### 5.6 图标体系（`components/CmIcon.vue`）

**为什么自绘**：小程序 `image` 不支持 SVG，字体图标要额外体积且微信端 `@font-face` 不稳。
本端图标全部用 `border` / `background` / `transform` 画，H5 与 mp-weixin 表现一致，换色只改 `currentColor`。

| 项 | 规范 |
|---|---|
| 画布 | 44×44rpx，线宽 3rpx，圆角 4–10rpx；三档尺寸 sm 36 / md 44 / lg 52（`transform: scale`，不改布局盒） |
| 语义色 | `tone`: ink（主文字）/ muted（弱化）/ brand / white / none（继承父级） |
| 现有名字 | home、grid、plus、chat、me、bell、heart、search、arrow、clock、box、location、check、shield、receipt |
| 用法 | **禁止**再用「♥ / 💬 / ⚑ / › / ⊕」这类字符当图标；字符字形随系统字体变化，是风格不统一的头号来源 |
| 扩展 | 新图标只加「不超过 3 个形状」的组合；超过就说明该处应该用图片而不是图标 |

### 5.7 品牌块（身份卡 / 渐变头）

- 用于「我的」身份卡、「广场」头图、登录页品牌头；**每页最多一块**，多了会互相抢
- 底色 `linear-gradient(135deg, #FFA05A, --brand, --brand-2)`，右上 + 左下各一团白色柔光（径向渐变 18%–34%）制造纵深
- 卡上文字一律白色；次要信息用 `rgba(255,255,255,.82)`，玻璃胶囊用 `.2` 白底 + `.45` 白描边
- 内容与卡的间距 ≥ 16pt；卡不做投影渐变过渡，只挂 `--shadow-md`（或同色 `.6` 透明度的彩色投影）

### 5.8 系统通知（信封列表 + 信笺弹层，2026-10-31 新增）

版式与 Web 同源（`01-Web用户端-UI设计规范.md` §4.8），小屏只做三处让位：面板改**底部抽屉**（圆角只留上两角，`max-height: 82vh`）、信纸内边距 24pt、正文 15pt / 行高 1.85。印章缩到 48pt，仍居落款左下方。

- 列表项：白卡 `--r-lg`，左侧 28×28 类型块，右侧标题（公告才有）+ 两行摘要 + 时间；未读右侧 6pt `--color-err` 实心点，已读不占位
- 页面头部右侧「全部已读」文字按钮，仅未读 > 0 时出现，点击后 `uni.showToast` 报「已全部标为已读」
- 点开抽屉即标该条已读；抽屉内除「关闭」外无第二个动作——通知不是待办，不需要"处理"
- 「我的」页「系统通知」格右上角红点，同样以未读数为准，进页面读完后 `onShow` 回来必须消失

## 七、交互与动效

v1.1 起动效不再是「有没有」的问题，而是**三条统一曲线 + 四类动作**。曲线混用是"生硬"和"廉价"的分界。

| 用途 | 曲线 | 时长 | 说明 |
|---|---|---|---|
| 入场（页面 / 列表 / 磁贴） | `cubic-bezier(.22,1,.36,1)` | 300–380ms | 快进慢出，像被轻轻放上去；列表错峰 30–40ms/项，上限 8 项后不再累加 |
| 按压反馈 | `ease-out` | 120–140ms | `scale(.97)` 或底色加深 8%；超过 160ms 会觉得拖 |
| 选中切换（dock 光块 / 左侧分类条） | `cubic-bezier(.22,1,.36,1)` | 300–320ms | 只动 `transform`，读起来是"滑过去"而不是"跳过去" |
| 强调回弹（角标、点开态） | `cubic-bezier(.34,1.56,.64,1)` | 220–260ms | 只给小元素用，大块回弹会晕 |
| 页面转场 | 系统默认 + 整页淡入 220ms | — | **只动 opacity**（见 §二 固定定位那条）；竖向位移交给内容块 |
| 骨架 → 内容 | 直接替换 | — | 不做交叉淡入，避免跳动 |
| 全局上限 | ≤380ms | — | 比 Web 端更严 |

**图标与文字的变化要同步**：选中时颜色与字重一起变（`--text-3`/400 → `--brand`/600），只变颜色会显得没选中。

**手势**：左滑返回（系统）、长按图片保存、下拉刷新、上拉加载。不引入自定义手势。

## 八、无障碍与文案

- 正文对比度 ≥ 4.5:1；`--text-3` 不承载必读信息
- 最小可点击区域 **44×44pt**（微信官方建议，比 Web 的 24px 大）
- 所有图片补 `alt` / 无障碍标签；纯装饰图标记 `aria-hidden`
- 文案口语化、短：按钮用动词（「我想要」「聊一聊」），不用「确认」「提交」
- 价格、时间格式与 Web 端一致（`¥18`／「3 小时前」）

## 九、落地约定（uni-app）

```
src/
├─ design/tokens.css     ← 与 Web 端共用 Primitive，覆盖本端 Semantic
├─ components/           ← GoodsCard / MomentCard / TabBar / CmIcon / ConditionTag
├─ styles/theme.scss     ← 全局视觉层（卡片 / 按钮 / 区块标题 / 动效），只在 App.vue 引一次
├─ pages/                ← M1–M12
└─ manifest.json / pages.json
```

- **禁止写死色值**，一律 `var(--*)`（小程序端落成 `$cm-*` 令牌，由 `pnpm tokens` 生成）
- uni-app 里 rpx 换算：`1pt = 2rpx`；`dist/uni.scss` 已把尺寸令牌 ×2 转 rpx，页面里直接用 `$cm-space-4` 拿到的是 32rpx
- 图标不再需要 png：统一走 `CmIcon`（纯 CSS 绘制，见 §5.6），`static/tabbar/` 已废弃
- 新增页面时：根节点挂 `cm-page`（tab 页再加 `cm-page--tab`），内容块按需挂 `cm-in` 做入场，**不要**给页面根节点加 transform
- 与 Web 用户端共用业务组件**逻辑**，模板各自实现

## 十、与另两端的关系

|---|---|
