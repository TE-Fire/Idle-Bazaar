## 一、设计原则

| # | 原则 | 落地判据 |
|---|---|---|
| 1 | **逛得下去** | 首页必须是无限流；用户第 3 秒内要看到至少 4 件商品，不能先看到搜索框和分类 |
| 2 | **图片压倒一切** | 卡片图片占比 ≥ 60%；文字只保留标题 + 价格 + 成色，其余折叠 |
| 3 | **拇指优先** | 所有高频操作落在屏幕下 1/3；发布按钮悬浮右下且避开安全区 |
| 4 | **半熟人信任可见** | 学号认证、同校、面交点三项必须能在卡片或详情页一眼看到 |
| 5 | **主色克制** | 橙色只给：发布按钮、选中态、价格。分类金刚区图标**各用一色**（2026-10-24 参考美团改版，取代早前「转转教训」的单色决定） |

## 二、小程序平台硬约束（先读，再设计）

| 约束 | 说明 | 应对 |
|---|---|---|
| 单位 rpx | 750rpx = 屏宽。基准屏 375pt → **1pt = 2rpx** | 本文档尺寸以 pt 表述，实现时 ×2 转 rpx |
| 顶部导航 | 系统导航栏右侧胶囊固定存在 | 自定义导航必须读取状态栏高度动态适配；**默认方案：用系统导航栏，不做自定义** |
| TabBar | `app.json` 配置，最多 5 项，icon 81×81 png，不支持 SVG / 不支持超过 5 项 | 5 项定为：首页 / 分类 / 发布 / 消息 / 我的 |
| 无 hover | 触屏没有悬停态 | 所有 hover 改为 `:active` 按压态（底色变深 8% 或缩放到 0.97） |
| 页面栈 | 最多 10 层，超出无法跳转 | 详情页 → 卖家主页 → 商品详情 的链路用 `redirectTo` 截断 |
| 字体 | 只能用系统字体；自定义字体需网络加载且首屏闪烁 | 中文字体栈：`-apple-system, "PingFang SC"`；数字用系统默认 |
| 安全区 | iPhone 全面屏底部 34pt 危险区 | 底部固定元素加 `padding-bottom: env(safe-area-inset-bottom)` |
| 图片 | 列表必须懒加载，否则长列表内存爆 | `image` 组件 `lazy-load`，列表页首屏外延迟加载 |
| 长列表 | 超过 100 条会卡 | 用 `scroll-view` + 分页；uni-app 下开启 `virtual-list` 或 `recycle-list` |
| 原生反馈 | 优先用 `wx.showToast` / `showModal` / `showActionSheet` | 不自己写 Toast 组件 |

## 三、Design Token

### 3.1 Primitive（三端共用，见 `01-Web用户端-UI设计规范.md` 2.1）

### 3.2 Semantic（小程序映射）

```css
:root{
  /* 主色：橙。与 Web 端的黄同属暖色高饱和家族，
     取深一档是因为小屏上黄底+黑字在小尺寸控件（Tab 选中、图标）可读性差，
     橙底白字在 44pt 以下控件上更稳。 */
  --brand:        #FF6A00;
  --brand-hover:  #E85F00;
  --brand-bg:     #FFF1E6;   /* 选中底色 */
  --brand-text:   #C25A00;   /* 浅底上的品牌文字 */
  --price:        #FF5500;

  --bg:      #F5F5F6;   /* 页面底 */
  --surface: #FFFFFF;
  --border:  #EFEFEF;
  --border-ctrl:#DCDCE2;
  --text-1:  #23232A;
  --text-2:  #6A6A6A;
  --text-3:  #A0A0A0;

  /* 间距：4pt 基准（=8rpx 步进） */
  --s-1:4pt; --s-2:8pt; --s-3:12pt; --s-4:16pt; --s-5:20pt; --s-6:24pt; --s-8:32pt;

  /* 字阶：body=14pt（28rpx），比 Web 端略大一号 */
  --f-xs:11pt;  /* 22rpx 元信息 */
  --f-sm:12pt;  /* 24rpx 次要 */
  --f-base:14pt;/* 28rpx 正文/卡片标题 */
  --f-md:16pt;  /* 32rpx 区块标题 */
  --f-lg:19pt;  /* 38rpx 价格 */
  --f-xl:22pt;  /* 44rpx 详情页标题 */

  --r-sm:4pt; --r-md:6pt; --r-lg:10pt; --r-xl:14pt;
  --sh-1:0 1px 3px rgba(20,20,30,.06);
  --sh-2:0 4px 14px rgba(20,20,30,.10);

  --tab-h:50pt; --nav-h:44pt; --safe-b:env(safe-area-inset-bottom);
}
```

**字重**：400 / 500 / 600 / 700。小程序内不要用 800（PingFang 无此字重会合成，发虚）。价格用 700。
**行高**：正文 1.6；卡片标题 1.35；价格 1.1。

## 四、布局与页面骨架

### 4.1 首页（P0，最重要的一页）

```
┌ 系统导航栏 44pt ────────────────────┐
│ [搜索框 32pt 圆角]        [消息图标] │   ← 吸顶，滚动时保持
├─ 金刚区（两行 5×2，10 格排满）────────┤   ← 分类入口，实色图标 + 白字（§5.3）
├─ 兴趣频道 chips（横向滑动，不吸顶）──┤
├─ 双列瀑布流 ─────────────────────────┤
│  ┌──────┐  ┌──────┐                  │   间距 8pt，卡片宽度 (屏宽-24-8)/2
│  │ 图   │  │ 图   │                  │   图片 4:3 或 3:4，高度不固定（瀑布）
│  │ 标题 │  │ 标题 │                  │
│  │ ¥价  │  │ ¥价  │                  │
│  │ 成色 │  │ 成色 │                  │
│  └──────┘  └──────┘                  │
│  （无限滚动，上拉加载更多）           │
└──────────────────────────────────────┘
  [悬浮发布按钮 ⊕ 56pt，右下，距底 20pt+安全区]
├─ TabBar 50pt（含安全区）─────────────┤
```

**关键**：瀑布流左右两列**不等高**是允许的，但同一列内必须对齐；卡片高度差由图片比例产生，文字区固定。

### 4.2 TabBar（5 项）

| 序 | 名称 | 图标 | 说明 |
|---|---|---|---|
| 1 | 首页 | 房子 | 默认页 |
| 2 | 分类 | 网格 | 全部分类树 |
| 3 | **发布** | 加号（橙底白字，直径 44pt 上凸 8pt） | 视觉重心，不用普通图标 |
| 4 | 消息 | 对话气泡 + 红点角标 | — |
| 5 | 我的 | 人形 | — |

选中态：图标 + 文字同为 `--brand`；未选中 `--text-3`。

## 五、组件规范

### 5.1 商品卡片（瀑布卡）

| 项 | 规范 |
|---|---|
| 宽度 | `(屏宽 - 24pt - 8pt) / 2`，375 屏约 171pt |
| 图片 | 圆角 10pt 上圆角，高度自适应（3:4 ~ 4:3 之间），`mode="aspectFill"` |
| 标题 | `--f-base`，最多 2 行，`line-clamp:2`，行高 1.35 |
| 价格 | `--f-lg` / 700 / `--price`；右侧可选「¥68」原价删除线 `--f-xs` `--text-3` |
| 元信息行 | 成色标签（绿描边）+ 校区，`--f-xs` `--text-3` |
| 卖家行 | 16pt 头像 + 昵称 + 认证小标（已认证才显示） |
| 角标 | 图片左上：「急出」「可议价」橙色小标，圆角 4pt |
| 按压态 | `:active` 缩放 `scale(.97)`，120ms；**不做阴影变化**（小程序渲染阴影性能差） |
| 间距 | 卡片间 8pt，距屏幕左右各 12pt |

### 5.2 搜索框

- 高 32pt，圆角 16pt，底色 `--bg`，左侧放大镜 `--text-3`，右侧可选「搜索」文字按钮
- 吸顶，随页面滚动不消失（首页）/ 详情页隐藏

### 5.3 金刚区（分类入口）

- 每行 5 个，两行共 10 个；不做横向分页（10 格排满：8 个字典一级分类 + 全部分类 + 发布）
- 分类数据走字典接口 `/api/dict/all`，**不得硬编码**（tech/02 §七）；色相按分类名映射，未登记分类回落灰
- 图标 48×48 实色圆角方（`--r-xl`）+ 白色粗体单字；「全部分类」白底描边弱化、「发布」品牌橙实色强化，用样式强弱做层级
- 点击反馈：整格可点，按下图标 scale(0.9) 快速回弹；入场错峰上浮（每格晚 40ms）
- 点击分类格带意图跳分类页并选中该一级分类（switchTab 不能带参，走 `utils/nav-intent.ts` 模块级一次性意图）
- 文字 `--f-xs` `--text-2`，单行省略号

### 5.4 成色标签（本平台核心组件）

| 评级 | 文案 | 颜色 |
|---|---|---|
| A | 全新未拆 | `--green-600` |
| B | 几乎全新 | `--green-600` |
| C | 轻微使用 | `--orange-400` |
| D | 明显使用 | `--text-2` |

四端（Web / 小程序 / 后台 / API）必须使用同一套 A–D 编码，文案与颜色一一对应。

### 5.5 其他

| 组件 | 规范 |
|---|---|
| 悬浮发布按钮 | 56pt 圆形，`--brand` 底白字 ⊕，右下距边 16pt，距底 `20pt + safe-area`；滚动时隐藏，停止滚动 300ms 后淡入 |
| 骨架屏 | 首屏用骨架卡（灰色块 + 微光动画），不用全屏 loading |
| 空状态 | 插图 + 一行文案 + 一个次要按钮；文案要具体（「这座校区还没有人发布教材」而非「暂无数据」） |
| 加载更多 | 底部「正在加载…」/「没有更多了」；禁止无限转圈 |
| 下拉刷新 | 保留系统默认样式，配色与 `--brand` 一致 |
| Toast | 用 `wx.showToast`，`icon:none`，时长 1500ms |

## 七、交互与动效

| 场景 | 时长 | 说明 |
|---|---|---|
| 按压反馈 | 120ms | `scale(.97)` 或底色加深 8% |
| 页面转场 | 系统默认 | 不自定义转场动画 |
| 骨架 → 内容 | 无动画 | 直接替换，避免跳动 |
| 悬浮按钮淡入 | 200ms | scroll 停止后 |
| 全局上限 | ≤300ms | 小程序性能预算更紧，比 Web 端更严 |

**手势**：左滑返回（系统）、长按图片保存、下拉刷新、上拉加载。不引入自定义手势。

## 八、无障碍与文案

- 正文对比度 ≥ 4.5:1；`--text-3` 不承载必读信息
- 最小可点击区域 **44×44pt**（微信官方建议，比 Web 的 24px 大）
- 所有图片补 `alt` / 无障碍标签；纯装饰图标记 `aria-hidden`
- 文案口语化、短：按钮用动词（「我想要」「聊一聊」），不用「确认」「提交」
- 价格、时间格式与 Web 端一致（`¥18`／「3 小时前」）

## 九、落地约定（uni-app）

```
src/
├─ design/tokens.css     ← 与 Web 端共用 Primitive，覆盖本端 Semantic
├─ components/           ← Card / Price / ConditionBadge / Skeleton / Empty / ActionBar
├─ pages/                ← M1–M11
├─ static/tabbar/        ← 81×81 png，选中/未选两套
└─ manifest.json / pages.json
```

- **禁止写死色值**，一律 `var(--*)`
- uni-app 里 rpx 换算：`1pt = 2rpx`，CSS 变量中的 pt 值需在构建时转换，或直接写 rpx 数值（推荐后者）
- TabBar icon 必须 81×81 png，无圆角、无透明边距超出
- 与 Web 用户端共用业务组件**逻辑**，模板各自实现

## 十、与另两端的关系

| 层 | 关系 |
|---|---|
| Primitive Token | ✅ 与 Web 用户端、管理端共用 |
| Semantic 主色 | 🔶 Web 用黄 `#FFD100`（黑字）、小程序用橙 `#FF6A00`（白字）；同一暖色家族，因屏幕尺寸与控件尺寸差异取不同档位 |
| 商品卡片 | ❌ 瀑布卡（本端）/ 网格卡（Web）/ 表格行（后台）三套模板 |
| 布局导航 | ❌ 底部 TabBar（本端）/ 顶栏 + 左筛选（Web）/ 左菜单 + 内容区（后台） |
| 数据可视化 | 本端仅保留「我的闲置浏览趋势」一个极轻图表，重图表全部在管理端 |
