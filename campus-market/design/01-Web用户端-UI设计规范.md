## 一、设计原则

| # | 原则 | 落地判据 |
|---|---|---|
| 1 | **主色只用一次** | 品牌黄只出现在：发布按钮、选中态、已选 chip。其余一律中性色。每个功能图标不得自带颜色 |
| 2 | **靠分割线分层，不靠阴影** | 全站阴影只用于「悬停浮起」和「对比条」两处，其余层级别用 `box-shadow` |
| 3 | **信息密度优先于留白** | 桌面一屏至少 12 件商品。宁可挤，不要空 |
| 4 | **桌面必须兑现移动端给不了的能力** | 常驻筛选、悬停预览、多对象对比、双视图、批量发布——缺一项则本端无存在意义 |
| 5 | **校园字段是一等公民** | 成色评级 / 校区 / 面交点 / 学号认证，四项必须在卡片、筛选、详情三处同时可见 |

### 2.2 Semantic（Web 用户端映射，写代码用这一层）

```css
:root{
  /* 色 */
  --brand:        var(--yellow-500);   /* 发布按钮 / 选中态 */
  --brand-hover:  var(--yellow-600);
  --brand-bg:     var(--yellow-100);
  --brand-border: var(--yellow-200);
  --price:        var(--orange-600);
  --bg:           var(--gray-50);
  --surface:      var(--gray-0);
  --border:       var(--gray-200);
  --border-ctrl:  var(--gray-300);
  --text-1:       var(--ink-900);
  --text-2:       var(--ink-600);
  --text-3:       var(--ink-400);

  /* 间距：4pt 基准 */
  --s-1:4px; --s-2:8px; --s-3:12px; --s-4:16px; --s-5:20px; --s-6:24px; --s-8:32px; --s-10:40px;

  /* 字阶：1.25 模数，body=14px（Web 端比移动端小一号，因为信息密度要求更高）*/
  --f-xs:12px;  /* 元信息、chip */
  --f-sm:13px;  /* 侧栏、描述 */
  --f-base:14px;/* 正文、卡片标题 */
  --f-md:16px;  /* 区块小标题 */
  --f-lg:20px;  /* 卡片价格、区块标题 */
  --f-xl:25px;  /* 详情页标题 */

  /* 圆角 */
  --r-sm:4px;   /* 标签 */
  --r-md:6px;   /* 输入框 */
  --r-lg:8px;   /* 缩略图、槽位 */
  --r-xl:12px;  /* 白卡（商品卡/筛选卡） */
  --r-2xl:16px; /* 促销卡位 / 悬浮工具栏 / 详情大容器（2026-09-30 闲鱼化改版新增） */
  --r-pill:999px; /* 胶囊：按钮 / 搜索框 / 排序与快捷分类 chips */

  /* 阴影：只有两处 */
  --sh-1:0 1px 3px rgba(20,20,30,.06);   /* 控件微影；白卡静置态的兜底 */
  --sh-2:0 4px 14px rgba(20,20,30,.10);  /* 卡片 hover 浮起 / 悬浮工具栏 */

  /* 结构尺寸 */
  --nav-h:60px; --side-w:240px; --content-max:1280px; --rail-w:72px;
}
```

**字重**：只用 400 / 600 / 700 / 800 四档。价格用 800，按钮用 700，正文 400，小标题 600。禁止 500。
**行高**：正文 1.6；卡片标题 1.45；大标题 1.4；数字/价格 1.1。

> **2026-09-30 闲鱼化改版**：整体风格向闲鱼 Web 版对齐（用户拍板）。核心四条：
> ① 白卡**去 1px 描边**，靠灰底 `--bg` 与白卡的明度差分层（描边是"表格感/简陋感"的主因）；
> ② 顶部取消第二条白色分类条，改为**通栏品牌黄导航**（logo + 白胶囊搜索 + 热搜词），
>    分类入口收进首页左侧「全部分类」白卡；
> ③ 首页铺**彩色促销卡位**（橙主推 + 黄/蓝/绿品类卡）与「猜你喜欢」胶囊组；
> ④ 新增右侧 72px **悬浮工具栏**（发布 / 消息 / 对比+角标 / 回顶部）。
> 本节以下按新口径修订。

## 三、布局与栅格

### 3.1 断点

| 断点 | 视口 | 内容区 | 商品列数 | 筛选栏形态 |
|---|---|---|---|---|
| sm | 375–767 | 100%，左右留白 16px | 2（瀑布流） | 底部抽屉 + 顶部 chips |
| md | 768–1023 | 100%，左右留白 24px | 3 | 顶部横向 chips |
| lg | 1024–1439 | 100%，左右留白 24px | **4 + 常驻侧栏** | 左侧常驻 240px |
| xl | ≥1440 | **锁 1280px 居中** | 5–6 | 左侧常驻 240px |

> 内容区超过 1600px 不再扩展——每行字数失控，可读性反降。

### 3.2 页面骨架（2026-09-30 闲鱼化改版后）

```
┌─ nav 通栏品牌黄（sticky，两行）──────────────────────────┐
│ Logo │ 白胶囊搜索框(max 560) │ 校区切换 发布闲置(黑底黄字) 消息 订单 │
│      └ 热搜词一行（黄底深色小字，点击即搜）      │
│ 登录态：28px 白环头像（无头像回退昵称首字）+ 昵称 + 编辑 + 退出 │
├──────────────┬─────────────────────────────────────┤
│ side 240px   │ 公告条（白卡胶囊，可关，仅纯首页）     │
│ sticky       │ 促销卡位（橙主推+黄/蓝/绿，仅纯首页）  │
│ 全部分类卡   │ 猜你喜欢胶囊组（选中黄底）             │
│ 价格双滑杆   │ 已选 chips                            │
│ 成色         │ 工具条（排序胶囊组 · 共N件 · 视图切换） │
│ 校区         │ 商品网格 4 列 / 列表视图               │
│ 卖家认证     │ 分页                                  │
│ 发布时间     │                                       │
└──────────────┴─────────────────────────────────────┘
  ─ 右侧悬浮工具栏 72px（fixed right，发布/消息/对比+角标/顶部）─
  ─ cmpbar 56px（fixed bottom，选中 >0 件时出现）─
```

- **检索态（`/list?cat=` / `?q=`）自动收起**公告条与促销卡位，让位给结果。
- 分类不再有独立横条：首页左卡 + 快捷胶囊 + 顶栏热搜词三个入口共用一个 `?cat`。
- 面包屑取消（闲鱼无面包屑）。

**栅格**：12 栏，gutter 16px。侧栏占 2.5 栏等效（固定 240px），内容区自适应。

## 四、组件规范

### 4.1 商品卡片（本端最重要组件）

| 项 | 规范 |
|---|---|
| 结构 | 图片区(4:3) → 标题行（标签chips前置+2行截断） → 三段式价格行 → 元信息行 → 底部卖家行 |
| 卡体 | **白底无描边**，圆角 12px，静置 `--sh-1`，hover `--sh-2` |
| 图片 | `aspect-ratio:4/3`；`object-fit:cover`；默认图与第二张图叠放，hover 交叉淡入 |
| 标题 | `--f-base`，行高 1.45，文本段 `-webkit-line-clamp:2`；**标题行内前置交易 chips**（包邮=红底 / 可议价=黄底），闲鱼把卖点放到第一眼 |
| 价格 | **三段式**：`¥` 小号 + 整数 `--f-lg`/800 + 小数小号，全 `--price`；右侧原价删除线 `--f-xs`，再右「N人想要」`--f-xs` `--text-3` |
| 元信息 | `--f-xs` `--text-3`；成色用绿色描边小标签 + 校区·面交点 + 右对齐相对时间 |
| 底部 | 18px 头像 + 昵称 + 右对齐信用标签（极好=黄chip / 已认证=绿chip）；**无上边框** |
| 角标 | 图片左上：急出=`--price` 底白字 |
| hover | `transform:translateY(-3px)` + `--sh-2`；180ms ease-out |
| 对比按钮 | 右上角胶囊，默认 `opacity:0`，hover 时浮出；hover 自身转黄底 |
| 圆角 | 12px，`overflow:hidden` |

### 4.2 按钮

| 变体 | 高度 | 底色 | 文字 | 用途 |
|---|---|---|---|---|
| primary | 36 / 46（详情页主行动） | `--brand` | `--text-1` / 700 | 发布闲置、我想要 |
| secondary | 28–46 | 白 + `--border-ctrl` | `--text-2` | 收藏、对比、清空 |
| text | — | 透明 | `--text-3` → hover `--text-1` | 清空全部、换一批 |

> **黄底必须配深色字**（`#FFD100` vs `#1F1F26` ≈ 12:1）。禁止黄底白字。
> **按钮一律胶囊形**（`--r-pill`，2026-09-30 起，闲鱼口径）；EP 主按钮在全局样式里统一覆写。
> 顶栏「发布闲置」是唯一**黑底黄字**反色块——黄底页面上权重最高的入口。

### 4.3 输入控件

- 搜索框：**白底胶囊**嵌在黄导航里（高 40px），右端胶囊黄按钮，下方热搜词一行——不再用黄描边矩形
- 普通输入：高 28–36px，1px `--border-ctrl`，圆角 6px，focus 时描边转 `--brand`
- 复选框：`accent-color:var(--brand)`，原生即可，不自定义图形
- 价格区间：两个 64px 输入框 + 双滑杆（填充段 `--brand`，滑块 14px 白底 2px 黄边）

### 4.4 标签 / Chip

| 类型 | 样式 | 用途 |
|---|---|---|
| 已选条件 | `--brand-bg` 底 + `--brand-border` 边 + 尾部 × | 筛选回显，点击移除 |
| 成色 | 绿字 + 35% 透明绿边 | 卡片、列表、详情 |
| 交易标签 | `.cm-tag--red`（包邮）/ `--yellow`（可议价）/ `--blue`（认证）/ `--green` | 卡片标题前置、详情卖点行 |
| 信用标签 | 极好=黄chip / 已认证=绿chip，右对齐 | 卡片底部卖家行 |
| 快捷分类 / 排序 | 白底胶囊，选中黄底黑字 700 | 猜你喜欢、排序胶囊组 |
| 状态角标 | 急出=橙红底白字 | 图片左上角 |

### 4.5 对比条（桌面独占）

- `position:fixed;bottom:0`，高 56px，白底无描边 + 上投影
- 4 个 66×50 槽位：已填显示缩略图 + 右上角 ×，空槽为虚线框 `+`
- 中间文案「已选 N / 4 件」，右侧：关闭 / 清空 / 开始对比（黄底主按钮）
- 出现条件：已选 ≥1 件；选中第 1 件时从下方滑入 200ms

### 4.6 侧栏筛选组

每组结构：`h4 标题（右对齐「清空」）+ 内容 + 1px 分隔线`。组间距 16px。整栏 `sticky`，`top = nav-h + 16px`（分类条取消后不再加 cat-h）。

### 4.7 右侧悬浮工具栏（2026-09-30 新增）

- `position:fixed; right:12px; top:30%`，宽 72px，白底圆角 16px + `--sh-2`
- 四项竖排：发布（黄圆图标）/ 消息 / 对比（红点角标=已选件数）/ 回顶部
- <1024px 隐藏（与常驻侧栏同一断点口径）

## 六、交互与动效

| 场景 | 时长 | 曲线 | 说明 |
|---|---|---|---|
| 卡片 hover 上浮 | 180ms | ease-out | 位移 3px，禁止超过 4px |
| 图片切换 | 250ms | ease | 交叉淡入，不做滑动 |
| 对比条滑入 | 200ms | ease-out | 仅首次出现时 |
| 视图切换 | 0 | — | 直接切换，不加过渡 |
| 页面内锚点 | 300ms | ease-in-out | — |
| 全局上限 | **≤400ms** | — | 超过即被视为迟钝 |

**反馈规则**：所有异步操作必须有 loading 态（按钮内 spinner 或骨架屏）；成功用 Toast（顶部居中，2s）；破坏性操作必须二次确认 Modal。

## 七、无障碍与文案

- 正文对比度 ≥ 4.5:1，`--text-3` 仅用于非关键元信息，不得承载必读内容
- 可点击区域 ≥ 24×24 CSS px；卡片整体可点，但「＋对比」需 `stopPropagation`
- 所有图标按钮补 `aria-label`；筛选组用 `fieldset + legend`
- 键盘：`/ `聚焦搜索、`Ctrl+Enter` 提交发布、`Esc` 关闭模态
- 价格统一 `¥` + 阿拉伯数字，不带小数时省略 `.00`；时间相对显示（3 小时前 / 昨天），超过 7 天显示绝对日期

## 八、落地约定

```
src/
├─ design/
│   ├─ tokens.css        ← 本文档 2.1 + 2.2 的 CSS 变量，唯一色值出处
│   └─ reset.css
├─ components/           ← Button / Card / Tag / Price / ConditionBadge / FilterGroup / CompareBar
├─ views/user/           ← P1–P9
└─ router/
```

- **禁止在组件里写死色值**，一律 `var(--*)`
- Tailwind 若使用，需在 `tailwind.config.js` 里把上述 token 映射为 `colors.brand` / `colors.price` 等，禁止直接用 `amber-400` 这类内置色
- 组件尺寸三档：`sm`（移动端）/ `md`（Web 用户端，本文档）/ `compact`（管理端）
- 与移动端、管理端共用 `tokens.css` 的 Primitive 层，各自覆盖 Semantic 层

## 九、与另两端的关系

| 层 | 与移动端（小程序） | 与管理端 |
|---|---|---|
| Primitive Token | ✅ 共用 | ✅ 共用 |
| Semantic 主色 | 🔶 分叉：Web 用黄 `#FFD100`（配黑字），小程序用橙 `#FF6A00`（配白字）。同属暖色高饱和家族，小屏上黄底黑字在小尺寸控件可读性差，故取深一档 | 🔶 分叉：管理端用蓝 `#1677FF`，属于工具型产品语义 |
| 基础组件 | ✅ 共用逻辑，尺寸不同 | ✅ 共用逻辑 |
| 商品卡片 | ❌ 三套模板（网格卡 / 瀑布卡 / 表格行） | ❌ |
| 布局导航 | ❌ 独立（顶栏 + 左筛选） | ❌ 独立（左菜单 + 内容区） |
